A stdlib-only Python program that writes one haiku about debugging — three
lines in the 5-7-5 syllable shape — to `/output/entry.txt`.

## The haiku

> midnight cursor blinks
> one red line accuses me
> it was my typo

## Run

```sh
python3 main.py
```

Honours `MAKEFUN_OUTPUT_DIR` if set, otherwise writes to `/output/entry.txt`.
The output is deterministic: byte-identical on every run.
